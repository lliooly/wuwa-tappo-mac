# 美术素材目录

原版 Wuwa Tappo 1.0.3 的素材已移至同级的 [独立素材仓库](../../wuwa-tappo-assets/README.md)。本目录保留素材分类路径和来源索引，图片、图标和字体通过相对符号链接指向独立仓库，供应用构建和来源核对使用。可以先看 [中文图鉴目录](_索引/remote/CATALOG.md)，按角色、配件和表情名称查找图片。

| 目录 | 内容 |
| --- | --- |
| [角色](角色) | 260 个角色外观的完整图、图鉴图、身体和头部分层；`内置默认` 保存客户端内置素材的原始名称。 |
| [配件](配件) | 135 个配件的素材图、图鉴图和内置默认素材。 |
| [表情](表情) | 504 个表情的素材图、图鉴图和内置默认素材。 |
| [界面](界面) | 原版界面、安装界面、登录界面，以及当前官方登录 SDK 快照中的图标和背景。 |
| [图标](图标) | Windows 原生图标、发行包图标和 ICO。 |
| [字体](字体) | 客户端内置的 12 个 WOFF2 字体。 |
| [_索引](_索引) | 素材来源、官方图鉴快照、对应关系、校验值和技术分析记录。日常浏览素材无需进入。 |

按 SHA-256 对独立的图片和字体文件去重后，相同内容只保存一份；不同用途或原有程序路径需要保留的名字使用相对符号链接指向同一份文件。例如，某些表情的图鉴图和素材图内容相同，但仍分别按用途列出。复制或移动时，请同时保留本项目与同级的 `wuwa-tappo-assets` 目录及其相对位置。

## 范围和校验

官方公开索引快照包含 899 个图鉴条目，指向 3,098 个图片地址；其中角色每套包含 1 张完整图、3 张身体分层和 2 张头部分层，另有图鉴图。公开图鉴包含未解锁素材，但没有个人账号解锁状态。

主程序、安装器和卸载器内的图片也已排查，包括嵌在 JavaScript/CSS 里的图片及 PE 原生图标。原版登录 SDK 使用滚动的 `1.x` 地址，相关素材来自 2026-10-30 的公开快照。

- [官方素材索引与中文名称](_索引/remote/metadata)
- [逐文件来源和 SHA-256](_索引/remote/manifest.json)
- [图鉴数据和素材路径](_索引/remote/catalog.json)
- [最近一次校验结果](_索引/verification.json)
- [首次逆向分析记录](../recovered/wuwa-tappo-cn-1.0.3/ANALYSIS.md)

3,098 个索引地址均已对应到本地分类文件，并通过 PNG 解码、尺寸及本地 SHA-256 校验。索引本身没有提供官方文件哈希，因此本地哈希用于检查归档是否发生变化。此范围以 2026-10-30 的客户端和公开索引为准。

原始前端、安装器、卸载器及 SDK 的 JavaScript/CSS 仍保留在 `recovered` 中：它们用于运行、分析和核对来源，部分文件本身包含 Base64 图片；原始 Windows 程序内部也包含资源。这些内嵌数据属于原文件的一部分。

如需重新抓取官方素材，`scripts/recover-remote-art.py` 要求通过 `--output` 指定独立的暂存目录；当前整理好的目录不会被直接覆盖。
