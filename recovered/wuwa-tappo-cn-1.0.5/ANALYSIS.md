# Wuwa Tappo 国服 1.0.5 Windows 版逆向分析

2026-11-20 对照用户提供的国服安装包与 [1.0.4 Windows 恢复记录](../wuwa-tappo-cn-1.0.4/ANALYSIS.md)。macOS 以 `657491d` 及 2026-11-16 的本地字体缓存和系统游戏模式修复为基线，应用版本为 1.0.5，首次适配的构建号为 12。build 13 去掉游戏模式设置组的绿色外框。build 14 调整设置与联机按钮、列表和分组标题。

从安装器偏移 `0x41680ab` 识别 NSIS 头，解出固实 LZMA 流，再以 PE 结构和版本资源确认主程序及卸载器。用同样流程重新提取 1.0.4，主程序及卸载器的 SHA-256 与上一版记录一致。

从 PE 节表换算 Tauri 表中的路径和 Brotli 流位置，恢复 [主程序前端](frontend/index.html) 的 132 项，解压后共 63,013,928 字节。与 1.0.4 相比，112 项路径和内容均一致。安装器和卸载器也各有 132 项前端资源，逐项解压后路径和哈希一致。主程序原始字节校验见 [清单](manifest.json)。

## 行为变化与 macOS 落点

| 范围 | 静态证据与适配 |
| --- | --- |
| 公开联机 | 主入口增加 `api/frontend/rooms/public` 和 `api/frontend/rooms/random-join`。桌宠通过房间号和角色状态更新公开选项。 |
| 房主管理 | 桌宠和房间面板处理成员移除及房主转让。Socket.IO 使用 `rk` 和 `rt`，macOS 沿用现有原生 WebSocket 传输。 |
| 设置 | 增加始终置顶、指针监控、游戏模式分组和重置应用。macOS 通过 AppKit 窗口层级控制置顶，停用指针监控时暂停位置轮询及桌宠鼠标交互，继续保留鼠标按键计数。 |
| 重置 | 前端先暂停计数输入，再请求保存。macOS 清理本应用的 WebKit 数据和登录钥匙串记录，保留点击数据。访客保留待同步计数，已登录用户按 CUID 保存累计值，重登时与服务器计数取较大值。 |
| 表情 | 背包可按当前角色筛选表情。与房间移除成员按钮共用一枚已更新的内联 PNG。其他独立图片和字体沿用素材库快照。 |
| 登录与续期 | 原版要求续期结果带有效 `expire_at_ms`，并在写回前确认请求使用的 token 仍属于当前会话。Mac 保留 Keychain 会话。 |
| 平台桥接 | 沿用 macOS 系统游戏模式联动、本地字体缓存修复、计数 ACK 防回退、GitHub Releases 更新及登录窗口适配。Windows 网络诊断的入口在 Mac 构建副本中停用。 |

原生导入表出现 `dnsapi.dll`、`iphlpapi.dll` 和 `winhttp.dll`。这与新增网络诊断模块相符，具体调用路径属于 Windows 版。本次依据静态发行文件及 macOS 回归结果，线上真实账号与跨账号房间操作需由实际会话确认。

## macOS 验收

- 27 项 JavaScript 回归通过，包含计数字符渲染、会话续期、公开房间与房主操作的消息契约。Swift 检查通过系统游戏模式日志游标、点击归档和独立 Keychain 会话的保存、恢复与清除。
- 使用独立 bundle ID 从临时目录启动 arm64 应用，通过背包、图鉴、合成、联机、设置和国内登录选择页的检查。原生验收覆盖置顶、指针监控、跨窗口快捷键、游戏模式双向联动和计数去重。未发现未适配的桥接命令或脚本异常。
- 应用采用 ad-hoc 签名，签名及 ZIP 内容已验证。实际线上账号、双账号跨端房间以及长时间内存占用未实测。
