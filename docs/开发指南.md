# 开发指南

当前默认路径为恢复的 CN 1.0.2 Vue/CSS 前端与 Swift 原生宿主。源码构建步骤见 [README](../README.md#快速开始)。

## 目录与外部输入

```text
父目录/
├── wuwa-tappo-assets/       # 独立素材库，必须相邻检出
└── wuwa-tappo-mac/
    ├── native/             # AppKit、WKWebView、输入、手柄与窗口
    ├── original-adapter/   # Tauri IPC／事件适配与原版运行检查
    ├── recovered/          # 不可修改的恢复前端、原始 manifest 与分析
    ├── assets/             # 原有分类符号链接、快照与来源索引
    ├── src/                # 旧实现的独立动作与渲染模块
    ├── panel/、preview/    # 旧面板和浏览器预览
    ├── scripts/、script/   # 构建、校验与恢复工具
    ├── tests/              # 动画与原版宝箱规则测试
    └── docs/               # 规格、验收与真实截图
```

素材库已验证提交为 `6fd82980bb8f193e88bfa21c15cbc5b6cae66f48`。两个仓库的相对位置和符号链接都必须保留；推荐使用 Git 克隆，不要复制单个目录或使用无法保留链接的解压工具。`recovered/` 部分图片、字体通过 `assets/` 指向相邻素材库，不能把这些链接误当重复文件删除。

Windows 原始安装包、主程序、卸载器及 IDA 数据库只作本地历史分析输入，已被 `.gitignore` 排除，不是构建应用所必需。部分 `recover-*` 工具仍需这些本地样本；没有样本时不能重做完整历史恢复。原档检查在样本存在时校验其哈希，但不执行 Windows 程序。

## 依赖分层

| 层次 | 依赖与用途 |
| --- | --- |
| 应用运行 | macOS 13+；Swift 使用 AppKit、WebKit、JavaScriptCore、GameController、ServiceManagement 等系统框架。不需要独立 WebKit、Node.js 或 Python 运行时。 |
| 应用构建 | Apple Silicon、Xcode Command Line Tools 或 Xcode，Python 3.9+ 标准库；调用 `xcrun swiftc`（Swift 5 语言模式）、`sips`、`iconutil`、`codesign`、`ditto`。 |
| JS 检查与测试 | Node.js 22+；`package.json` 无 dependencies／devDependencies，不需要 npm 安装，也没有需锁定的 npm 依赖树。 |
| 历史素材恢复／检查 | 部分 `recover-*.py` 与 `verify-art-archive.py` 额外使用 Pillow；`requirements-art.txt` 固定已使用的 11.3.0。构建应用不需要它。 |
| 原版前端 | 已打包的 Vue、Pinia 等第三方代码；不是可通过 npm 重新安装或升级的原始 Vue 工程。版本与许可依据原始声明，见 [第三方说明](../THIRD_PARTY_NOTICES.md)。 |

没有 Cargo、Swift Package Manager 或 Tauri 原生构建流程；兼容层实现原版所需的平台命令。此处没有声称已完成所有嵌入依赖的漏洞审计。

若需要历史素材工具，使用隔离 Python 环境：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-art.txt
```

## 构建与签名

```sh
python3 scripts/build-macos.py
# 已有 Node.js 时也可以：npm run build:macos
```

脚本会重建 `dist/Wuwa Tappo.app`，校验所用素材哈希、应用声明补丁、编译 arm64 可执行文件并签名压缩。运行中的应用需要先正常退出，避免替换尚在使用的包。

已配置开发者签名身份时：

```sh
WUWA_SIGN_IDENTITY='你的本机代码签名身份' python3 scripts/build-macos.py
```

此变量只选择已有身份，不导入证书，也不会自动完成公证。请勿提交私钥、证书、Apple 账号或公证凭据。

重建并重启到面板的便捷命令：

```sh
./script/build_and_run.sh --settings
```

该脚本先向旧实例发送 SIGTERM 并等待保存退出；仍未退出时会停止构建，不强杀尚在保存的应用。

## 检查层次

```sh
# 不需要 .app，但需要相邻素材库
python3 scripts/check-repository.py
node --test tests/animation.test.js
python3 scripts/verify-click-store.py
python3 scripts/verify-session-store.py

# 以下在构建 .app 后执行
npm test
python3 scripts/verify-original-port.py
python3 scripts/verify-package.py
python3 scripts/verify-standalone.py
```

- `check-repository.py`：恢复文件哈希、所有受版本控制的符号链接、原创 Python 语法、README 的本地资源和锚点。
- 动画测试：独立旧模块的时序、输入去重、生命周期、图层用途和偏移。
- 会话检查：使用唯一临时 Keychain 服务验证读写、重启恢复和清理，并检查日志脱敏；不访问应用的生产会话。受限执行环境可能不能访问 Keychain，需要正常 macOS 会话运行。
- 计数存储检查：编译实际 Swift 存储实现，使用隔离偏好验证旧数据迁移、确认后清零、账号替换、环境隔离和非法写入；不访问账号服务。
- 完整 `npm test`：另外从恢复档及实际 `.app` 提取原版宝箱表达式执行，不能在没有构建产物时宣称全套通过。
- 原档检查：比对 132 份文件、构建副本声明补丁及本地资源映射。
- 包检查：核对签名、Info.plist 和 ZIP 文件内容。
- 独立运行检查：复制应用到临时目录，以隔离的 bundle identifier／偏好启动，验证实际原版页面和交互并导出 `build/` 报告。

CI 在 Linux 上检出固定版本素材库，仅运行静态检查、原创 JS 语法和基础动画测试。macOS UI、输入权限及真实硬件不由 CI 证明。历史验收材料中的 `build/*.json` 是本机生成数据，不随 Git 上传；[验收报告](最终验收结果.md) 保留结果与复核方法。

## 实际输入采样与日志

```sh
open -n -W 'dist/Wuwa Tappo.app' --args --check-input --input-report "$PWD/build/original-input-sample.json"
```

通过 `.app` 进行权限检查；授权后采样 60 秒，仅输出事件数量与计数变化。缺少权限时报告 `permission unavailable`。菜单栏可查看监听状态，日志位于 `~/Library/Logs/Wuwa Tappo/`，不要将个人日志提交到仓库。

睡眠恢复、开机启动、手柄、双屏和全屏自动游戏模式，需要在实际 macOS 会话中复核。验收时注明应用版本、签名变化及权限状态。

## 旧实现与调试预览

旧手写实现只用于回退和历史分析，不代替默认原版前端的验收：

```sh
'dist/Wuwa Tappo.app/Contents/MacOS/WuwaTappo' --legacy-ui
'dist/Wuwa Tappo.app/Contents/MacOS/WuwaTappo' --smoke-test
'dist/Wuwa Tappo.app/Contents/MacOS/WuwaTappo' --panel-preview "$PWD/build/legacy-panel.png"
npm run preview
```

浏览器打开 <http://127.0.0.1:4173>。预览仅响应页面内输入，不监听其他应用，不接真实手柄；每 5 秒闭眼 250 ms。端口冲突时运行 `python3 scripts/preview-animation.py --port 4174`，Ctrl+C 停止。

旧动作模块接口：`keyDown()`／`keyUp()`、`mouseButton('press'|'release')` 和 `clap()`；手柄 pulse 调用 `clap()`，避免重复投递。有效 `keyUp()` 返回 true 时计数；鼠标／手柄有效 press 在输入层计数。远端 `applySide()` 与 idle 的处理仅保留模块能力，未接入真实联机。

`start()` 开始眨眼，`resetInput()` 清理中断输入，`dispose()` 销毁实例；`resolveLayers()` 按头、身体、配件输出统一坐标，不以图鉴或完整图替代分层。详细设计及历史记录见 [动画规格](superpowers/specs/2026-10-30-animation-design.md)。

## 在线诊断

正常启动保留官方 HTTP、Socket.IO 和 CN 登录 SDK。`--offline` 可显式离线；原版截图／集成检查自动离线，不读取生产 Keychain 会话。业务 token 使用独立 Keychain 项，避免自定义 `wuwa://` 下 Secure Cookie 无法保存的问题。SDK 自身的存储继续由官方 SDK 管理。

```sh
./script/build_and_run.sh --online-check
```

这会打开原版登录窗口，并定时更新 `build/online-state.json`。报告仅含网络、会话存在与登录就绪标记、库存条目数量和房间模式，不含手机号、验证码、token 或账号标识；命令本身不请求验证码。只在需要诊断时使用，普通启动不写该报告。
