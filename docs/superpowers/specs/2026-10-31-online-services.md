# 官方在线业务接入

用户已批准复用原版业务逐项实现并验证，并要求每部分完成后 commit、push。使用当前 main，不创建 worktree。recovered 原档保持不变，适配通过构建副本、独立 JavaScript 桥和 Swift 宿主完成。

## 顺序与完成标准

1. 修正计数存储：按环境分离本地待同步计数与账号累计对象；验证旧数据迁移、重启、清零、账号切换。
2. 恢复网络基础：官方公开配置、词典、素材目录、图鉴；验证 WebKit 来源、会话和多窗口共享。Windows 更新器保持禁用。
3. 接通 CN 通行证 SDK 与 UID 登录：复用原版表单、验证、角色查询、业务 token、续期、登出及恢复。手机号使用通行证 SDK；UID 不接受手机号。
4. 接通真实用户资料、背包、收藏、换装、表情和预设，重新读取数据核对结果。
5. 复用 Socket.IO 大厅及 cr 累计上报，验证断线、在途输入、登出与退出保存。
6. 接通开箱、两类合成和兑换；超时先读取真实状态，不自动重复消耗请求。
7. 验证房间创建、加入、离开、解散、远端动作、表情和外观；与官方客户端双向验收。
8. 补齐维护公告、认证失效与强制断开；完成独立包和离线回归。

## 架构与约束

Vue/Pinia、业务 HTTP 封装、SDK 登录和 Socket.IO 状态机使用恢复产物。主窗口持有业务状态，面板通过原版快照与事件更新。原生宿主负责平台存储、窗口、网络通知及必要的网络适配。先验证 WebKit 原生网络，确有来源限制再使用限定官方服务的原生请求桥。

会话凭据仅本机保存，不写入仓库、报告或日志。SDK 和通路就绪后才尝试登录，避免重复验证码；遇到频率限制停止重试。用户授权读取 Messages 中本次登录验证码，不读取无关消息。Mac 自动更新另行设计，遥测不随业务联网自动开启。

原版 Cookie 使用 Secure/SameSite=None，不能假设 wuwa:// 兼容。需验证持久化及跨窗口同步。认证错误按原版清理会话，网络错误不伪装登出或成功。

load_key_press_count 返回数字；load_cumulative_click_count 返回 count/cuid/environment 对象。累计、余额、消耗不可混用。旧离线计数仅迁移到 CN 正式环境，不复制到多个环境。公开素材缓存与账号库存分离，选图继续遵守素材仓库的用途映射。
