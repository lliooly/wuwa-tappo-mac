# 全解锁离线版实现计划

已获得用户批准，直接编写计划代替本机缺失的 writing-plans 技能。

1. 增加显式 `--offline-full-atlas` 构建参数，隔离应用名、Bundle ID、可执行文件、ZIP、版本变体及日志；普通构建保持现有行为。
2. 从固定素材目录生成可校验的全物品背包及原版外观目录，保留图鉴与佩戴素材的用途区别。
3. 增加由原生主线程统一管理的本地存档模块，处理换装、收藏与预设，校验角色限制和表情数量，广播状态给所有窗口。
4. 在构建阶段接入原版前端的背包、外观与预设函数，关闭特别版的账号和房间初始化，移除在线入口并标明离线版。
5. 扩展构建运行脚本及 CI，提供特别版独立产物和说明。
6. 验证存储行为、前端语法、普通版回归、特别版打包及复制到仓库外的全新存储启动、交互与重启恢复。

恢复原档及素材仓库保持不变。仅对构建副本应用有锚点校验的补丁。
