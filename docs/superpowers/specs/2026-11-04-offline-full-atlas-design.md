# macOS 全解锁离线特别版

日期：2026-11-04。状态：用户已批准，已完成本地实现与验收。

## 交付方式

在当前仓库的 `dev/offline-full-atlas` 分支开发，不创建 worktree。普通联网版继续由 `main` 维护；本次不修改 `main`，不自动发布 Release。

特别版应用名为 `Wuwa Tappo Offline.app`，安装包为 `Wuwa-Tappo-mac-offline-full-atlas-arm64.zip`，输出至 `dist/`。Bundle ID 使用 `io.lliooly.wuwa-tappo.mac.offline-full-atlas`，与普通版共存。设置和存档也必须隔离，包含 WebKit 网站数据和显式使用固定名称的存储位置，不能只改 Bundle ID。

版本沿用当前 CN 前端基底版本，增加明确的“全解锁离线版”标识；包内元数据记录发行变体。构建入口显式选择特别版，普通构建命令和产物名称保持现状；特别版 CI 使用独立的 artifact 名称。

## 用户行为

首次启动无需账号和网络，默认启用完整本地图鉴。角色、配件和表情可自由选择，保留原版角色专属适配规则和表情数量限制。保留桌宠动作、键鼠与手柄响应、换装、收藏、预设、显示与输入设置；外观、收藏和预设在重启后恢复。

特别版不提供在线账号与离线模式切换。隐藏登录、房间、兑换、合成及服务器开箱入口；点击仅作本地响应和统计，不产生服务器点数、物品或奖励。保留输入监控权限引导。

## 架构与数据流

复用 Swift 宿主、恢复前端和现有构建补丁机制，保留恢复原档。独立的本地图鉴模块负责目录到背包的转换、装扮、收藏、预设和持久化；通过窄接口接入原版状态与交互，不复制参考项目的 Windows 宿主或本地 HTTP 服务。

从构建时固定的素材快照生成本地目录，并将所需图片、字体和界面资源随包携带。通过既有 `wuwa://` 资源机制读取。图鉴 ID 与素材 ID 使用显式映射，不能直接复用或按名称拼接路径。

全解锁是本地背包视图：将完整目录转换为本地可用物品，不导入账号存档，也不伪造线上所有权。外观选择只更新特别版的本地状态。各窗口共享状态，保存后通知桌宠及其他已打开窗口刷新。

本地状态包含版本号、所选外观、收藏和预设；由单一持久化入口完成校验和保存，避免多个窗口覆盖彼此更新。新安装选择一个素材完整的默认角色，失效条目恢复为合法默认值并提示。

## 离线与素材约束

特别版启动时强制使用离线配置，不加载普通版 Keychain 会话。宿主阻止 HTTP、WebSocket 等远程请求及远程页面导航，前端关闭登录、远程图鉴、公告、SDK、遥测和更新初始化。外部项目或来源链接只能由用户主动打开系统浏览器。

遵守相邻素材仓库的 AGENTS.md 和使用指南：物品格取 `files.atlas`，桌宠取同一来源的头身分层，佩戴配件与触发表情取 `files.image`。角色与图鉴 ID 分别处理，按角色元数据应用配件偏移，保留透明画布。

构建发现必要素材缺失或校验失败时明确失败；运行时资源或存档异常应提示并提供合法默认状态，不能联网补图或静默挪用其他用途的素材。保留版权、来源和非官方声明。

## 验证与验收

有针对性的自动测试覆盖完整背包生成、ID 映射、角色限制、表情上限、收藏和预设、存档校验及跨窗口更新。包检查核对特别版名称、Bundle ID、版本标识、签名、ZIP 和资源完整性。

构建后用隔离的全新存储验证首次断网启动、三类物品换装、收藏、预设和重启恢复，并检查无远程业务请求。验证应用复制到仓库外仍可运行；普通版与特别版可以并存，特别版不读取或覆盖普通版的会话、外观与计数。

运行适用的现有检查，确认普通构建入口仍可用。交付本地特别版应用、ZIP 和构建说明；上传或发布发行版本另行按用户要求执行。
