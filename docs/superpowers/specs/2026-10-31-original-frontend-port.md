# 原版前端完整未登录功能移植

未登录移植于 0.2.0（build 7）完成，结果见 [验收记录](../../最终验收结果.md)。

用户目标：停止继续开发登录功能，复用已恢复且可读的原版Vue/CSS发行文件，完整复现未登录可用的UI与逻辑。这里的完成标准不是把已有手写页面补到“看起来差不多”，而是原版组件和状态流真实运行，平台行为逐项验收。

## 路线和边界

以 `recovered/wuwa-tappo-cn-1.0.3/frontend` 为不变的证据来源。构建脚本复制到应用Resources/original；原档不编辑。`prepare-original.py`对构建副本应用可计数、可审计的适配补丁，包内adapter-manifest.json记录源哈希及补丁。Vue组件、CSS、菜单动画、筛选器、原有表情/换装/说明页面优先原样保留，不再逐页手写复刻。

AppKit + 系统WebKit托管多个原版路由窗口；通过单独Tauri兼容层实现事件、窗口和系统命令。主窗口与面板继续采用原版cat-panel-state/cat-panel-action数据流，不以本地另造的背包模型代替原版状态机。注意Tauri会JSON序列化Vue Proxy，WK直接传对象会丢失代理数组；适配层必须保持相同序列化语义。

所有账号登录、验证、官方物品写操作、真实开箱、服务端合成和联机加入不在本目标内。保留原版未登录的入口、禁用或提示状态，不伪装账号已解锁或操作成功。公开图鉴、素材名词典属于未登录可读取的数据，使用素材整理阶段保存的官方公开快照；与账号库存严格分开。Windows安装器/卸载器/Windows自动更新安装程序属于发行平台专用功能，需在Mac上解释或替换为对应打包能力，不能执行.exe。

## 安全与来源

本阶段不需要账号信息。原版遥测初始化与调用被显式替换为本地空实现，避免未初始化SDK反过来打断UI；CSP和fetch/WebSocket适配阻止原版外网请求。官方词典和公开图鉴读取本地快照，文件路径按整理仓库catalog映射；不抓取新账号数据。所有原版代码的引入、替换和静态索引都写入构建记录。

原版Windows的输入钩子和窗口命令不能直接在macOS执行，因此“Vue/CSS可读”解决的是UI和业务前端的复用，不会自动补齐原生后端；完成目标仍包含剩下的平台适配。
