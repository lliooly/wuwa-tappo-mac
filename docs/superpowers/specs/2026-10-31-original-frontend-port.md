## 路线和边界

以 `recovered/wuwa-tappo-cn-1.0.2/frontend` 为不变的证据来源。构建脚本复制到应用Resources/original；原档不编辑。`prepare-original.py`对构建副本应用可计数、可审计的适配补丁，包内adapter-manifest.json记录源哈希及补丁。Vue组件、CSS、菜单动画、筛选器、原有表情/换装/说明页面优先原样保留，不再逐页手写复刻。

AppKit + 系统WebKit托管多个原版路由窗口；通过单独Tauri兼容层实现事件、窗口和系统命令。主窗口与面板继续采用原版cat-panel-state/cat-panel-action数据流，不以本地另造的背包模型代替原版状态机。注意Tauri会JSON序列化Vue Proxy，WK直接传对象会丢失代理数组；适配层必须保持相同序列化语义。

所有账号登录、验证、官方物品写操作、真实开箱、服务端合成和联机加入不在本目标内。保留原版未登录的入口、禁用或提示状态，不伪装账号已解锁或操作成功。公开图鉴、素材名词典属于未登录可读取的数据，使用素材整理阶段保存的官方公开快照；与账号库存严格分开。Windows安装器/卸载器/Windows自动更新安装程序属于发行平台专用功能，需在Mac上解释或替换为对应打包能力，不能执行.exe。

### 原生宿主与退出

桌宠使用不激活应用的 NSPanel，不能成为键盘窗口；WK 视图接受首次点击。原版命中区域决定透明主窗口是否接收鼠标；实际鼠标事件直接进入 WK，不再重复合成 DOM 点击。面板拖动保存真实鼠标按下事件；边缘缩放读取原版 value 方向，并按原版 CSS 最小尺寸及 WebKit 缩放限制窗口。

面板本身会在按下左键时发送 pet-clap，因此全局鼠标通路需要排除同一次面板左键，避免双计数。此项已重新构建并通过模拟全局事件与面板事件的合并检查，计数只增加一次；接口检查仍不能代替授权后的真实点击验证。

macOS 应用菜单提供设置、编辑与退出。Command-Q 已通过原生 UI 触发，original-quit.json 记录 systemRequestedExit=true，说明系统退出经过原版保存流程。SIGTERM 也接到同一个退出流程；构建脚本等待旧实例退出再替换包，最终包已通过 SIGTERM 验证，见 build/final-sigterm.json。

开机启动使用 SMAppService；requiresApproval 不冒充已启用。显示器、安全边距、前台全屏检测、Dock 图标、日志与外链、手柄监听均已接入对应原生接口。关于与开源声明已通过实际打开、关闭检查。Windows 更新器禁用；账号网络状态保持 offline，不周期重试。

原包是 CN 分支：APP_REGION 为 CN，初始语言固定 zh。保留这一分支的原版语言入口及词典行为，不额外暴露 GLOBAL 分支的语言选择。多语言资源的存在不代表 CN 界面提供切换功能。
