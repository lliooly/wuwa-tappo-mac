# Wuwa Tappo macOS 移植设计

> 历史方案：前一次 Mac 实现已清理，本文件仅保留当时的目标与思路，具体技术方案需要在重新开发时再确定。

## 目标

为 Apple Silicon macOS 制作独立的悬浮桌宠，界面交互参考 Codex 桌面宠物，复用 Windows 1.0.3 程序中恢复的角色素材和客户端逻辑。用户希望尽量使用官方账号，并与原版同步计数及后续的宝箱、背包、合成和联机数据。

## 实现顺序

1. 建立 Tauri 2 原生外壳，提供透明、可拖动的桌面悬浮窗，展示原版角色及输入计数。
2. 用 macOS 原生事件监听记录键盘和鼠标的操作次数，持久化本地计数，处理授权被拒绝或撤销的情况。监听只用于计数，不保存输入文本。
3. 接入恢复的官方登录页面与客户端协议，验证账号状态、计数同步和断线恢复；不假设官方服务端支持该客户端。
4. 在前述链路可用后，逐步接入宝箱、背包、图鉴、合成和房间联机。

## 边界

原始 Windows 可执行文件无法在 macOS 上直接运行；窗口管理和全局输入由 macOS 实现。官方服务端不在样本中，登录和跨平台同步的兼容性必须用真实服务测试。原始前端与素材保留在 `recovered/`，适配代码放在独立目录，避免覆盖分析结果。

## 验证

- 自动验证计数持久化、恢复和计数合并，避免网络失败时丢失未同步的数据。
- 在 macOS 上启动应用，检查透明窗口、拖动、关闭、权限状态和输入计数。
- 使用用户主动完成的官方登录验证账号和同步；在原生《鸣潮》窗口化与全屏状态下检查悬浮窗与输入监听。
- 对尚无法接入或实测的功能明确标注状态，不以模拟数据表示官方同步成功。
