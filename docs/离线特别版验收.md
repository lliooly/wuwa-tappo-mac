## 复现

```sh
python3 scripts/build-macos.py --offline-full-atlas
python3 scripts/verify-offline.py --ui
```

结构化证据由检查脚本写入 `build/offline-first-launch.json`、`build/offline-validation.json` 和 `build/offline-validation.json.png`。这些生成文件不提交到源码仓库。

界面检查通过面板事件驱动原生窗口，使用临时隔离存储。验收覆盖本地装扮流程，实体键鼠和手柄输入可在应用的菜单栏测试。
