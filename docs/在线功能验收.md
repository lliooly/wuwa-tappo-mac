# 在线功能记录

验收日期：2026-10-31。以下记录来自原版函数检查、实际 Mac 运行及用户操作反馈。

| 功能 | 验收结果 |
| --- | --- |
| CN 通行证登录 | 通过原版 SDK 完成短信验证码登录。 |
| UID 登录 | 提交验证码后进入账号页面，显示资料、累计点击和退出入口。 |
| 会话保存 | 登录信息存入 Keychain，应用重启后恢复账号。 |
| 背包与图鉴 | 从官方服务读取账号库存，加载 899 条公开图鉴。 |
| 换装与收藏 | 配件切换和恢复正常，收藏重新读取后保留。 |
| 搭配预设 | 创建、读取和删除正常，兼容字符串形式的预设 ID。 |
| 点击同步 | 原版 Socket.IO 上报收到确认；等待确认期间新增的点击继续保留。 |
| 好友房间 | 两个账号双向进房，均显示 2/20 人；动作、表情、换装同步，以及退出和解散均获用户确认。 |
| 宝箱 | 开箱后服务器消耗和库存更新，重启后读回一致；奖励动画和冷却显示正常。 |
| 合成与兑换 | 用户补测反馈正常。 |

HTTP 请求、Pinia 状态和 Socket.IO 消息规则沿用原版。macOS 适配会话存储、系统命令与 WebSocket 传输。维护页通过隔离离线副本检查；认证清理、普通错误处理和并发续期通过包内原版函数检查。

## 自动检查

0.3.0（build 8）发布时，22 项 JS 检查、132 份原档与资源映射、签名和 ZIP 内容检查通过。最终包的独立五页离线回归于 2026-10-31 通过。

本地报告位于 `build/`：

- `online-state.json`：在线连接、会话和房间状态。
- `maintenance-check.json`：维护页检查。
- `standalone-pages.audit.json`、`standalone-validation.json`：独立运行结果。
- `package-verification.json`：签名、版本和 ZIP 内容。

源码与消息说明见 [在线服务设计](superpowers/specs/2026-10-31-online-services.md) 和 [联网接口索引](原版联网业务索引.md)。本次版本整理的检查结果见 [验收记录](最终验收结果.md)。
