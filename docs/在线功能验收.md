日期：2026-10-31。源码以 main 为准；本轮为在线能力开发，尚未宣布全部完成。离线基线的 build 7 验收见 [原报告](最终验收结果.md)。

| 能力 | 实现与证据 | 仍待验证 |
| --- | --- | --- |

| 累计计数 | 原版 Socket.IO `cr` 已多次成功确认；待同步与累计存储分离，确认期间新增点击不清零 | 长时间多设备并发使用的服务端冲突策略 |
| 房间 | 真实创建房间、获取单人成员快照；重启后恢复同一房间和房主身份 | 第二账号加入、双方动作／表情／外观同步、退出和解散 |

| 两类合成 | 原版升阶／平阶选择和接口保留；真实账号两种模式均提示材料不足，不能提交 | 有足够材料后的真实成功流程 |
| 兑换 | 保留原版提交与库存刷新接口 | 有效兑换码及真实领取结果 |
| 维护通知 | 用隔离离线副本触发原版维护页，确认面板渲染、主桌宠隐藏且无缺失原生命令 | 不声称官方服务器实际返回了维护响应 |

业务 HTTP、Pinia 状态和 Socket.IO 的消息／ACK／重连规则继续使用原版。macOS 仅适配会话、平台命令和 WebSocket 传输：浏览器握手曾返回 403；URLSession 原生传输已成功连通，TLS 校验未关闭。普通启动默认使用原生传输。

主程序遥测保持关闭，已识别的 SDK 分析地址由 WebKit 内容规则阻止。Windows 更新器保持禁用；Mac 自动更新没有作为原版 Windows 安装流程执行。
